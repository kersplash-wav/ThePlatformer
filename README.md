## Set-Up Instructions
Download the repository and open the project in a IDE which supports Java. If using NetBeans, you can click the green play button to run the project. If using any other Java-supporting IDE, go to src/platformer and specifically run the main.java file. You must have an extension or a built-in GUI framework which allows the Java GUI to open.

## Controls
| Action | Key |
| :--- | :--- |
| Jump | `Spacebar`, `W`, `Up Arrow` |
| Move Left | `A`, `Left Arrow` |
| Move Right | `D`, `Right Arrow` |
| Fast Fall | `S`, `Down Arrow` |
| Quit | `Esc` |
