## Set-Up Instructions
Download the repository or git clone it, and then open the project in a IDE which supports Java. If using NetBeans, you can click the green play button to run the project. If using any other Java-supporting IDE, you must be in the folder root and then click `run code` on the main.java file, located in src/platformer. You must have an extension or a JDK which allows the Java GUI to open. Given the project size, it may take 30-60 seconds for the project to be fully indexed. If the project is fully indexed, the code will most likely not run.

## How we built our project
We built _Platformer_ using Java as the primary and only programming language. NetBeans was originally used as the IDE for this project (hence the `nbproject`), although we later switched to Visual Studio Code for added convenience and better collaboration. We used Java documentation (ex. [docs.oracle.com](https://docs.oracle.com/javase/8/docs/api/javax/swing/JFrame.html)) to assist in our learning, helping us build the camera, physics, movement, and more.

## Challenges we encountered
Our largest challenge was being unable to complete all of our desired objectives within the project timespan. Several ideas were devised, including split-screen gameplay to allow multiple players, a level screen, and a more intricate sprite with animations. However, some of these ideas proved to be too complex and were abandoned after days of work (ex. split-screen), whilst other ideas simply were not developed due to a lack of time.

## Accomplishments we're proud of
We're very proud to have built this game from the ground up! Without using a game engine such as Unity or Unreal Engine, we had to learn the mechanics of making a game without any extra help, and we were absolutely able to figure things out in the end. The fact that our work resulted in an engaging game is something we're very prideful of.
